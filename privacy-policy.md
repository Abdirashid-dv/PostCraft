# PostCraft Privacy Policy

**Effective Date:** May 1, 2025

Thank you for using **PostCraft**. Your privacy is important to us. This Privacy Policy explains what information we collect, how we use it, and your rights in relation to that information. PostCraft is committed to being transparent and respectful of your data privacy.

---

## 1. Information We Do Not Collect

PostCraft does **not collect**, **store**, or **transmit** any of the following:

-   Personal information (e.g., name, email, location)
-   Social media credentials or content
-   User activity or behavior
-   Any identifiable browsing data

We do not use analytics tools, tracking scripts, or cookies within the extension.

---

## 2. Use of Permissions

PostCraft uses the following Chrome extension permissions strictly to provide its functionality:

### `activeTab`

-   Allows the extension to interact with the current browser tab where the user initiates a post or comment.
-   Used solely to read or modify content fields for enhancement suggestions.
-   No data is saved, transmitted, or analyzed beyond the user's local browser session.

### `host` Permissions (e.g., `https://twitter.com/*`, `https://www.linkedin.com/*`)

-   Required to inject the UI tools into supported social media platforms.
-   The extension only accesses and modifies elements necessary to enable AI features, such as text input fields.

### `scripting`

-   Enables PostCraft to inject custom functionality (e.g., buttons, popups) into supported websites.
-   All scripts execute locally and only interact with page elements relevant to the user experience.

### `storage`

-   Used to save settings (e.g., the Gemini API key) within the browser’s local storage.
-   This data is never transmitted to any external server and remains entirely within the user’s control.

---

## 3. Use of Gemini API Key

-   PostCraft requires users to enter their **own Google Gemini API key**.
-   This key is stored **locally** on the user’s device using Chrome's secure `storage` API.
-   All API requests are made **directly from the user’s browser to Google's Gemini service**.
-   PostCraft does **not** log, intercept, or transmit the API key or any data sent through it.

---

## 4. Data Handling & Security

-   All data processed by the extension (such as post content or comment generation) remains in your browser and is used only to generate responses from Gemini based on your request.
-   No data is sent to PostCraft servers (we do not operate any).
-   No third-party tracking or advertising scripts are used.

---

## 5. Open Source Transparency

PostCraft is fully open source. You can inspect the source code to verify that no data is collected or transmitted. The project is hosted on [GitHub](https://github.com/your-repo-url).
